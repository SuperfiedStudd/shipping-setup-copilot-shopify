# Shipping Setup Copilot

Shopify APM take-home prototype for reducing shipping setup abandonment.

## Live Demo

[https://shopify-take-home-liard.vercel.app/](https://shopify-take-home-liard.vercel.app/)

## Product Hypothesis

Shopify already has shipping tools, but small merchants can still miss setup details that make checkout rates wrong. This prototype brings the next missing shipping step into one visible, guided admin surface.

## What the Prototype Shows

- two-minute story rail
- simplified setup rescue
- Sidekick-style prompt help
- safer default settings by business type
- merchant approval before final settings

## Tech Stack

- Next.js
- TypeScript
- Tailwind
- local mock data
- Vercel

## Local Run

```bash
npm install
npm run dev
npm run build
```
